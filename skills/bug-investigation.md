# Skill: Bug Investigation

## Purpose
Investigate a bug: capture symptoms, reproduce, and gather evidence about the failure.

## When to use
For bug-type work items, before root-cause analysis.

## Expected inputs
- Bug report text, reproduction steps, environment details, relevant logs.

## Expected outputs
- A clear symptom description, expected vs actual behavior, and a set of evidence-backed observations.

## Important rules
- Separate symptoms from causes.
- Record reproduction conditions precisely.
- Cite evidence for every observation.

## Failure / uncertainty
- If the bug cannot be reproduced, record this as an unknown and identify what is needed to reproduce it.
