# Skill: Confluence Research

## Purpose
Discover and extract documentation related to a work item from Confluence.

## When to use
After analyzing a ticket, when documentation context is needed.

## Expected inputs
- Search terms, ticket context, known product/service names.

## Expected outputs
- Relevant pages with their contents summarized and cited.

## Important rules
- Read-only.
- Cite the source page for every extracted claim.
- Distinguish documented fact from interpretation.

## Failure / uncertainty
- If no relevant documentation exists, record "no documentation found" as a finding, not a dead end.
